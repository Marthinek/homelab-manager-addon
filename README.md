# Homelab Manager add-on repository

Home Assistant add-ons for the Homelab Manager project.

## Installation

In Home Assistant, open **Settings → Apps → App store → Repositories** and add:

`https://github.com/Marthinek/homelab-manager-addon`

## Security

The add-on connects to a Homelab Manager API endpoint configured by the administrator. API credentials belong in the add-on configuration and must never be committed to this repository.

The controller and inventory source code live in the private repository:
https://github.com/Marthinek/homelab-manager
